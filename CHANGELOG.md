# Changelog

## 0.2.2

- Documented and enforced the MoonBit `v0.10.9` minimum toolchain in CI and release documentation.

- Added advanced metrics, quality gates, alerts, route ranking, explanations, sensitivity analysis, and time-series helpers.
- Added deterministic benchmark cases and CLI commands.
- Added multi-platform all-target CI, coverage checks, generated-interface checks, and manual Mooncakes publishing.

## 0.1.0
