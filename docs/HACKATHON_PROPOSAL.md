# MoonBit 八月黑客松项目申报书：moonbit-eta-predict

项目拟建设一个 MoonBit 原生的流式 ETA 预测库，面向物流调度、外卖骑手、校园摆渡车、仓储 AGV 等需要在噪声观测下持续更新到达时间的应用。核心目标不是绑定某个地图服务，而是沉淀可复用的基础能力：一维卡尔曼滤波、观测异常门控、自适应滑动窗口、路段历史画像、实时 ETA 推断和误差评估。当前 MoonBit 生态中尚未看到成熟的 ETA/卡尔曼交通预测包，本项目可补齐“实时预测小型引擎”这一方向，并为后续 WebAssembly、边缘设备和云端调度场景留下扩展空间。

技术方案采用分层结构：`types.mbt` 定义观测、路段和结果模型；`kalman.mbt` 负责速度序列滤波和异常观测抑制；`window.mbt` 根据方差动态调节时间窗口；`profile.mbt` 表达路段自由流、常态、拥堵速度与可靠度；`eta.mbt` 作为门面把实时速度与历史速度加权融合；`metrics.mbt` 提供 MAE、RMSE、MAPE 等验收指标。第一阶段交付确定性算法和 CLI 示例，第二阶段补充 CSV/JSON 数据接入、路段日历、批量校准和更多后端示例。

MoonBit 适合本项目的原因在于：其编译和测试工具链轻量，类型系统能清晰表达领域模型；生成到 Wasm 后可嵌入浏览器、边缘网关和服务端；`moon check`、`moon test`、`moon fmt --deny-warn`、`moon info --deny-warn` 能形成稳定的质量闭环。仓库将采用 Apache-2.0 开源许可证，保留完整提交历史、README、来源说明、CI 和可运行测试，确保他人可以复现构建并理解边界。

预期验收成果包括：不少于一个可运行 CLI demo；覆盖核心路径和边界情况的测试；公开 README 与 MoonBit checked 文档；GitHub Actions CI；`pkg.generated.mbti` 接口信息；清晰的来源说明和后续路线图。开发计划按公开仓库推进，持续拆分提交，避免一次性堆积代码。黑客松版本重点证明预测引擎本身可靠、可维护、可扩展，后续版本再接入真实轨迹数据和业务系统。
