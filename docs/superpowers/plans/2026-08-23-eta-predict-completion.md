# ETA Prediction Completion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the ETA prediction library as a usable MoonBit package with verified production source above 6,000 lines, real deterministic benchmark output, expanded boundary coverage, mature documentation, CI, and registry packaging.

**Architecture:** Keep the root package as the public facade and split responsibilities into cohesive `.mbt` files. Extend the current streaming engine with validation, interchange codecs, calendar-aware route behavior, batch forecasting, calibration, and benchmark/report helpers without changing existing public names.

**Tech Stack:** MoonBit stable toolchain, MoonBit standard library, GitHub Actions, `gh`, Mooncakes registry.
